# Excel MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build local Python stdio MCP server `excel-mcp/` that reads/writes real `.xlsx` headless + headed with paranoid approval, backups, and IB-grade formatting.

**Architecture:** Single `excel-mcp` server, dual-engine `core/` (`headless.py` openpyxl + `headed.py` pywin32 COM) behind `engine.py` dispatcher; `server.py` thin stdio wrapper; `guard.py` + `versions.py` + `audit.py` enforce paranoid flow; `shots.py` thumbnails + on-demand PNG.

**Tech Stack:** Python 3.11+, `mcp` Python SDK, `openpyxl`, `pywin32`, `pillow`, `pytest`

**Spec:** `docs/superpowers/specs/2026-10-13-excel-mcp-design.md`

## Global Constraints

- Python `>=3.11`. Deps pinned in `excel-mcp/pyproject.toml`: `mcp`, `openpyxl`, `pywin32`, `pillow`, `pytest`.
- New code ONLY in `excel-mcp/`. Do NOT touch `sentinel/`.
- Transport V1 is stdio only. `core/` must not import MCP transport; `server.py` must contain no openpyxl/COM logic.
- Default engine `mode="headless"`. Every tool takes `mode: "headless" | "headed"`.
- Max 100000 cells per write call — reject above with `{status:"rejected", reason:"split into batches"}`.
- COM retry 3x backoff 200/500/1000ms on `RPC_E_CALL_REJECTED` / `PermissionError`, then `{status:"needs_retry"}`. Atomic: on exception restore `.bak`.
- Backups: sidecar `<Name>.versions/<ts>_<tool>_<range>.bak` + `.json`, keep 20 FIFO, git-ignored.
- Audit line: `ts | tool | path | sheet:range | backup_id | macro_sha256? | result`. Macro text never logged verbatim (SHA256 only). Errors append with `ERROR`.
- IB defaults verbatim: header fill `002060` white bold 10, body `Arial 10`, inputs `D9E1F2`, int fmt `_-* #,##0_-;-* #,##0_-;-* "-"_-;_-@_-`, pct `%_0.0%`, grid border `D9D9D9` thin, widths 14-18, row height 15, `FitToPagesWide=1 FitToPagesTall=0` landscape footer `&F | &A`.
- Whitelist: `ALLOWED_ROOTS` env/config; `..` traversal rejected; absolute path must prefix-match. Gated tools without valid approval return `{status:"needs_approval", diff}` and never write.
- `audit.log` and `*.versions/` git-ignored. `test_headed.py` is `@pytest.mark.needs_excel`, skipped when COM unavailable. CI runs headless-only.

## Review Focus

- Locked file mid-write leaves half-written xlsx — expect auto-restore `.bak` + `{status:"needs_retry"}`. Pinned in Task 3 test `test_backup_restore_on_apply_crash`.
- COM `Excel.Application` busy/detached at call time — expect 3x retry then `headed_unavailable_fell_back` warning, never crash. Pinned in Task 7 test `test_headed_detached_falls_back`.
- Path `../../secret.xlsx` or `C:\Windows\foo.xlsx` outside whitelist — expect `rejected` before any backup/audit-write. Pinned in Task 2 test `test_traversal_rejected_no_side_effects`.
- `.xlsm` with auto-macro asking to run without `macro_approved:true` — expect `needs_approval`, no execution, SHA logged only. Pinned in Task 9 test `test_macro_without_flag_never_executes`.
- 200k-cell `write_range` on a big model — expect `rejected split` without touching disk. Pinned in Task 4 test `test_oversize_rejected_untouched`.

def test_roundtrip_values_formulas(tmp_path):
