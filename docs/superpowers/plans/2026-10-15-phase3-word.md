# Phase 3 Word MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dual-mode Word server ships beside Excel and PowerPoint with the same paranoid flow and IB memo styling.

**Architecture:** Scaffold + trust primitives first, headless document core second, headed + engine + shots + server wiring third, golden memo fixture + gate last. Each task ends with an independently testable deliverable; the single gate (word suite) decides the phase.

**Tech Stack:** Python >=3.11, `python-docx` (pinned, new), `pywin32==312` (`Word.Application`), `mcp==2.3.0`, `pillow==12.3.0`, `pytest>=8`.

**Spec:** `spec.md` §9 (R10–R12, N8–N9, D23–D25, Q5–Q6) + `phases/phase_3.md` (AC-1–AC-4). Requires Phase 2 green. Executors read spec + phase contract + this plan.

## Global Constraints

- Python `>=3.11`. Excel/PPT pins unchanged; Word adds `python-docx` pinned in `word-mcp/pyproject.toml`.
- New code ONLY in `word-mcp/`. Do NOT touch `sentinel/`, `excel-mcp/`, `ppt-mcp/`.
- `word-mcp/core/` transport-agnostic (no MCP imports); `server.py` thin stdio only; own venv + suite per N7.
- Default engine `mode="headless"` on every tool; headed always `Visible=True` (D19); `needs_word` tests skip (never error) where COM is absent.
- COM busy → retry 200/500/1000ms then `{status:"needs_retry"}` + `.bak` restore; detached → `{warning:"headed_unavailable_fell_back"}`.
- Same paranoid flow: denylist → exact-`ops_hash` approval → copy-before-write backup (20 FIFO, git-ignored) → dispatch → audit append → `{ok, backup_id, thumbnail}`.
- IB memo values verbatim from spec §9/R12: headings white bold on `002060`, body `Arial`, accounting-style tables, footer page numbers, Letter.
- `audit.log` and `*.versions/` git-ignored. Sentinel runtime: DS `npm run check` per save, OP watches per `sentinel/howtowork.md`.

## Review Focus

- Long memo read returns whole document instead of the asked range — expect range-scoped reads with explicit bounds. Pinned in Task 2 range test.
- Heading style applied as direct formatting instead of the style object, so `apply_theme` can't restyle later — expect style-based headings. Pinned in Task 3 style test.
- Table cell shading lost on headed save roundtrip — expect byte-stable styles headless and headed. Pinned in Task 4 roundtrip test.
- Word disconnect (`0x80010108` class, seen on Excel/PPT 2026-10-15) crashes instead of fallback — expect retry-then-`headed_unavailable_fell_back`. Pinned in Task 4 stress test.
- Fixture with real client data committed — expect synthetic-only fixture, no names/figures traceable to a live deal. Pinned in Task 5 fixture review step.

def test_headed_unavailable_falls_back(tmp_path):

    out = dispatch("read_text", {"path": str(f), "start": 0, "end": 1, "mode": "headed"})

def test_write_needs_approval_then_succeeds(tmp_path):
    f = tmp_path / "d.docx"; make_doc(str(f))
    first = call_tool("add_paragraph", {"path": str(f), "text": "X", "style": "Normal"})
