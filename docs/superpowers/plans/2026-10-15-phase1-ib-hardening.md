# Phase 1 IB Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove Excel survives daily IB use with a real-model golden fixture, verbatim formulas (incl. circular), headed stress handling, and frozen regression pins.

**Architecture:** Tests + fixture first (P1.1), headed stress second (P1.2). New files only under `excel-mcp/tests/`; `core/` touched only fix-to-green with no interface changes. Single gate: full pytest suite.

**Tech Stack:** Python >=3.11, `openpyxl==3.1.5`, `pywin32==312`, `pillow==12.3.0`, `pytest>=8`, COM `Excel.Application`.

**Spec:** `spec.md` §7 (R1–R5, N1–N4, D13–D18) + `phases/phase_1.md` (AC-1–AC-4). The plan argues from the spec; executors read both.

## Global Constraints

- Python `>=3.11`. Pinned: `mcp==2.3.0`, `openpyxl==3.1.5`, `pillow==12.3.0`, `pywin32==312`.
- New files ONLY in `excel-mcp/tests/` (+ fixture). Do NOT touch `sentinel/`.
- `core/` changes are fix-to-green only: no new exported interfaces, no signature changes.
- Default engine `mode="headless"` everywhere; `needs_excel` tests skip (never error) where COM is absent.
- Max 100000 cells per write — reject above with `split into batches`, file bytes untouched.
- COM busy → retry 200/500/1000ms then `{status:"needs_retry"}` + `.bak` restore; detached → `{warning:"headed_unavailable_fell_back"}`.
- Backups sidecar `<Stem>.versions/`, 20 FIFO, git-ignored. Audit line `ts | tool | path | sheet:range | backup_id | result`.
- IB values verbatim from spec §5: header `002060` white bold 10, body `Arial 10`, inputs `D9E1F2`, int `_-* #,##0_-;-* #,##0_-;-* "-"_-;_-@_-`, pct `%_0.0%`, grid `D9D9D9` thin, widths 14-18, height 15, `FitToPagesWide=1 Tall=0` landscape footer `&F | &A`.
- `audit.log` and `*.versions/` git-ignored. Sentinel runtime: DS `npm run check` per save, OP watches per `sentinel/howtowork.md`.

## Review Focus

- Circular formula gets evaluated or blocked instead of stored verbatim — expect byte-identical roundtrip, no exception. Pinned in Task 2 test `test_formulas_verbatim_and_circular_safe`.
- Footer side sections set to `None` so concatenation reads `"None&F | &ANone"` — expect `""` sides, center verbatim. Pinned in Task 3 footer assert.
- `golden_ib.json` schema rewritten without its paired test update — expect frozen keys, test reads same keys. Pinned in Task 3 schema test.
- COM `0x80010108` disconnect mid-suite (observed 2026-10-15) treated as failure instead of retried/fallback — expect retry-then-`needs_retry`/`fell_back`, never half-write. Pinned in Task 4 stress tests.
- Oversize write partially applies before rejection — expect `ValueError` before any disk touch, bytes identical. Pinned in Task 2 pins test.

```python
@pytest.mark.needs_excel
def test_headed_realmodel_roundtrip(tmp_path):
    f = tmp_path / "m.xlsx"; build(str(f))
    out = dispatch("read_range", {"path": str(f), "sheet": "Comps", "cell_range": "A1", "mode": "headed"})
    assert out.get("values") is not None or out.get("warning") == "headed_unavailable_fell_back"

def test_busy_locked_needs_retry_no_halfwrite(tmp_path):
    f = tmp_path / "m.xlsx"; build(str(f))
    before = f.read_bytes()
    out = dispatch("write_range", {"path": str(f), "sheet": "Comps", "cell_range": "A1", "values": [[1]], "mode": "headed"})
    assert out.get("status") in ("ok", "needs_retry") or out.get("warning") == "headed_unavailable_fell_back"
    assert f.read_bytes() == before or out.get("status") == "ok"

def test_detached_falls_back(tmp_path):
    f = tmp_path / "m.xlsx"; build(str(f))
    out = dispatch("read_range", {"path": str(f), "sheet": "Comps", "cell_range": "A1", "mode": "headed"})
    assert "values" in out or out.get("warning") == "headed_unavailable_fell_back"
```
